# README icon style

These icons reuse the original geometry in the workspace's canonical semantic registry. All use a 24-unit square, 1.6-unit rounded strokes and a 5-unit corner radius on the backing.

| Role | Value | Source |
| --- | --- | --- |
| Primary accent | `#e4cd92` | Moonlight gold in `qt_app.PALETTES` |
| Backing | `#1b2928` | Moonlight canvas in `qt_app.PALETTES` |
| Secondary diagram accent | `#70eedc` | Teal waygate/light identity |

The gold-and-forest family follows the Verdant Trials cover. The opaque dark backing keeps the outline visible on both GitHub themes. Each decorative image has empty alt text and an adjacent descriptive heading in the README.
